# Financial Engineering

Welcome to the **Financial Engineering** repository. This project serves as a comprehensive collection of resources, theoretical research papers, spreadsheets, and practical Python implementations covering key quantitative finance and financial engineering concepts.

---

## 📁 Repository Structure

```text
FinancialEngineering/
├── Excel 101/          # Basic to intermediate Excel models for financial concepts
├── Papers/             # Theoretical research papers and foundational readings
├── Python code/        # Python scripts & Jupyter Notebooks for quantitative analysis
├── Spreadsheets/       # Advanced Excel & spreadsheet models
└── Sharpe_1964.pdf     # Capital Asset Pricing Model (CAPM) seminal paper by William F. Sharpe


🧰 Key Features & Contents
Python & Jupyter Notebooks: Practical implementations of financial modeling, risk analytics, and quantitative methods using Python.

Spreadsheets & Excel Models: Pre-built financial models and templates ranging from basic calculations to advanced financial engineering applications.

Academic Papers: Foundational quantitative finance literature, including William F. Sharpe’s 1964 landmark paper on Asset Prices and Market Equilibrium.
